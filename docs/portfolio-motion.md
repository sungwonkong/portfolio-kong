# 포트폴리오 모션

## 참고한 사례

- [Brittany Chiang](https://brittanychiang.com/): 어두운 배경, 마우스 위치를 따라오는 조명과 절제된 카드 반응. 실제 사이트를 데스크톱 브라우저로 확인했다.
- [Rauno Freiberg](https://rauno.me/): 실제 첫 화면에서 짧은 fade 진입 애니메이션을 확인했다. 현재 포트폴리오에는 콘텐츠 진입의 짧은 타이밍을 참고했다.
- [Josh W. Comeau — Boop!](https://www.joshwcomeau.com/react/boop/): 호버 시 잠깐 반응하고 돌아오는 미세 인터랙션 개념을 버튼 화살표에 적용했다.

디자인과 소스 코드를 복제하지 않고 기존 포트폴리오의 어두운 테마에 맞게 구현했다.

## 적용

- 히어로 제목·설명·기술 태그·CTA 순차 등장.
- 배경 그리드, 천천히 이동하는 조명과 신호 라인.
- 마우스 위치에 반응하는 히어로·프로젝트·경력 카드 조명. 터치와 모션 줄이기 설정에서는 비활성화.
- 섹션 제목·프로젝트 카드·경력 카드의 첫 스크롤 진입 모션.
- CTA 화살표의 짧은 반응과 버튼 누름 피드백.
- CSS scroll timeline 지원 브라우저의 상단 읽기 진행 표시.

CSS, Web Animations API, IntersectionObserver로 구현했다. 새 패키지 의존성은 추가하지 않았다. 포인터 갱신은 requestAnimationFrame으로 제한하고 React 렌더링을 유발하지 않는다. 본문은 기본적으로 표시되므로 JS 또는 관찰 API가 없어도 숨겨지지 않는다. `prefers-reduced-motion` 변경 시 실행 중인 모션을 취소하고 CSS 애니메이션과 전환을 끈다. 이벤트·관찰자·프레임·진입 애니메이션은 언마운트 시 정리한다.

## 검증

빌드·린트·diff 검사를 통과했다. Chromium 1440×1000에서 시간에 따른 배경 transform 변화, 포인터 좌표 갱신, Enter 키 프로젝트 선택, 경력 펼침과 대비 검사(위반 0)를 확인했다. 모션 줄이기 설정으로 변경했을 때 실행 중 애니메이션이 0이 되고 콘텐츠가 계속 보임을 확인했다. 390px 모바일의 수평 넘침 없음과 JS 비활성화 시 콘텐츠 표시도 확인했다.
